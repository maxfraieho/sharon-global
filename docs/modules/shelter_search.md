# Модуль пошуку укриттів (shelter_search)

Модуль забезпечує пошук реальних цивільних укриттів та бункерів у радіусі навколо заданих GPS-координат. Він використовує дані OpenStreetMap через Overpass API для фільтрації лише життєздатних об'єктів, виключаючи павільйони та зупинки, та підтримує кешування результатів для підвищення надійності.

## Призначення
Основна мета модуля — надати користувачам системи `uav-watcher` актуальний список безпечних місць (укриттів) у безпосередній близькості від їхнього поточного місцезнаходження. Модуль реалізує стратегію "спочатку реальні дані, потім резервні", щоб гарантувати наявність результатів навіть при відсутності інтернету або порожньому запиті до карти.

## Архітектура
Модуль працює за принципом гібридного пошуку:
1.  **Первинний запит:** Використовує Overpass API для отримання вузлів та шляхів з тегами цивільного захисту (`civil_defence`, `emergency`, `building=bunker`).
2.  **Фільтрація:** Програмно відсіює небажані типи укриттів (пікнічні навіси, зупинки, альтанки) на основі тегів `shelter_type`.
3.  **Кешування:** Результати зберігаються у локальному JSON-файлі з TTL 24 години для швидкого доступу та зменшення навантаження на зовнішні API.
4.  **Fallback:** Передбачено механізм використання статичних даних (seed) у разі невдачі запитів або відсутності даних у кеші.

## Ключові функції

- `_haversine(lat1, lon1, lat2, lon2)` — обчислює відстань між двома точками на поверхні Землі у метрах за формулою гаверсинусів. Використовується для фільтрації результатів за радіусом.
- `_query_overpass(lat, lon, radius_m)` — формує та виконує запит до Overpass API для пошуку об'єктів у заданому радіусі. Фільтрує результати, виключаючи типи `_SKIP_TYPES`, та повертає структурований список укриттів з координатами та назвами.
- `_load_cache()` (очікується) — завантажує попередньо збережені дані з файлу `shelters_cache.json`.
- `_save_cache(data)` (очікується) — зберігає отримані дані у кеш-файл з перевіркою часу життя (TTL).

## Потік виконання
1.  Система отримує GPS-координати користувача.
2.  Модуль перевіряє наявність актуальних даних у локальному кеші.
3.  Якщо кеш застарілий або відсутній, формується запит до Overpass API з фільтрами на реальні укриття.
4.  Отримані дані фільтруються (виключаються альтанки, зупинки тощо).
5.  Результати сортуються за відстанню від точки користувача.
6.  Дані кешуються для наступних запитів.
7.  У разі помилки мережі або відсутності даних у OSM, система переходить до використання статичного набору даних (seed).

## Залежності

- **Зовнішні API:**
  - `https://overpass-api.de/api/interpreter` — для пошуку об'єктів на карті.
  - `https://nominatim.openstreetmap.org/reverse` — для зворотного геокодування (отримання адреси за координатами).
- **Бібліотеки Python:**
  - `asyncio` — для асинхронних операцій.
  - `math` — для геодезичних розрахунків.
  - `json`, `urllib` — для роботи з API та парсингу даних.
- **Локальні файли:**
  - `data/shelters_cache.json` — файл кешу результатів пошуку.
  - `data/` — директорія для статичних даних (seed).
