# Sharon-Global Architecture

## 1. Архітектура

Sharon-Global є глобальною мультитенантною системою моніторингу кризових ситуацій, що використовує архітектуру, яка поєдує багатотенантну архітектуру для даних та єнієлентну для сповіщень.

* **Многотенантна архітектура для даних:** Широкий доступ до даних для різних клієнтів, з використанням ідентифікації та авторизації для забезпечити безпечність.
* **Єнієлентна архітектура для сповіщень:** Проста, зрозуміла та ефективна система сповіщень, яка забезпечує швидкі та надійти повідомлення.

## 2. Ключові компоненти та їх призначення

* **UAV-Watcher (keyword_classify, ai_classify):** Монторингу кризових ситуацій з використанням швидкого keyword-прекласифікації та AI класифікації через LLM.
	+ **keyword_classify:** Висяє на 11 вузлів, забезпечуючи швидкі та точні класифікації keywords.
	+ **ai_classify:** Висяє на 8 вузлів, використовуючи LLM для більш точної класифікації.
* **Send Notification (19 вузлів):** Відправка сповіщень з використанням RESTful API.
* **Send All Clear Notification (12 вузлів):** Відправка сповіщень, коли кризові ситуації вирішуються.
* **Knowledge Graph:** Висяє на 30 вузлів, забезпечуючи інтеграцію та пов'язування різних компонентів.

## 3. Потік даних: Канали → Класифікація → Dispatch

* **Канали:** Управління та збіром даних з різних джерел.
* **Класифікація:** Монторинг та класифікація даних з використанням UAV-Watcher.
* **Dispatch:** Відправка сповіщень з використанням Send Notification та Send All Clear Notification.

## 4. Таблиця модулів

| Модуль | Вузли | Описание |
| --- | --- | --- |

| Send Notification | 19 | Відправка сповіщень |
